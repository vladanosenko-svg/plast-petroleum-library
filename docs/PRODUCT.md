# Концепция продукта

«ПЛАСТ» — рабочее название русскоязычной библиотеки книг, статей, учебных пособий и инженерных материалов по нефтегазовой отрасли. Основное действие — поиск по знаниям. Аудитория: студенты, инженеры, геологи, петрофизики и специалисты по разработке месторождений.

Текущая версия — frontend-прототип с демонстрационными данными. Реальные AI, RAG, backend и автоматическое пополнение библиотеки не входят в этап.
