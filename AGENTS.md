# Постоянные правила проекта

- Интерфейс по умолчанию русский.
- Сохранять editorial/minimal visual language; не превращать сайт в SaaS dashboard.
- Поддерживать светлую и тёмную темы через design tokens.
- Адаптивность для мобильных устройств обязательна.
- Не добавлять AI/backend-функции без отдельной задачи.
- Сохранять существующую архитектуру без технической причины для её изменения.
- Перед крупными изменениями изучать существующий код; после изменений запускать проверки.
